# 천국에 살고, 천국에 가고 — 묵상편지공방

독립 실행 가능한 한국어 묵상편지 웹사이트입니다. 날짜를 표시하지 않으며, 원문 묵상과 경건의 글, 개역개정 성구, A·K 응답, 지정 찬양을 담았습니다.

## 파일

- `index.html`: 디자인, 본문, 글 수정·파일 내려받기·인쇄 기능
- `vercel.json`: Vercel 정적 배포 설정
- `.gitignore`: 로컬 설정 및 비밀 파일 제외

## GitHub에 올리기

새 저장소를 만들고 이 폴더의 파일을 저장소 최상위에 올립니다. ZIP 파일 자체를 올리는 것이 아니라 압축을 푼 파일을 올립니다.

## Vercel 배포

1. Vercel에서 Add New → Project를 선택합니다.
2. 이 GitHub 저장소를 Import합니다.
3. Framework Preset은 Other, Root Directory는 저장소 최상위로 둡니다.
4. Build Command와 Install Command는 비워 둡니다. Output Directory는 `.`입니다.
5. Deploy를 누릅니다. API 키나 환경 변수는 필요하지 않습니다.

`vercel.json`에 위 설정이 들어 있습니다. Git 연동을 마친 후 기본 브랜치에 올린 변경은 Vercel에서 자동 배포됩니다.

## 로컬 확인

이 폴더에서 `python3 -m http.server 8000`을 실행하고 http://localhost:8000 을 엽니다.

## 글 수정과 공유

- 글 수정 → 수정 저장: 현재 브라우저의 기기에 저장합니다.
- 편지 파일 내려받기: 현재 화면의 수정본을 HTML 파일로 보관하거나 전달합니다.
- 편지 링크 복사: 서버에 게시된 원문 주소를 복사합니다.
- 모든 방문자에게 수정본을 보여주려면 GitHub의 index.html을 수정하고 커밋하여 재배포합니다.
- 이 사이트에는 로그인, 서버 저장소, 관리자 계정이 없습니다. 방문자가 기기에서 고친 내용은 다른 방문자나 GitHub에 자동 반영되지 않습니다.
- 찬양은 https://youtu.be/KM86EbdNjy4 입니다. 영상 삽입 재생이 제한될 경우 YouTube에서 찬양 듣기 링크를 사용합니다.

## 콘텐츠

성경 번역 표기와 경건의 글 저자 표기를 유지합니다. 성경 인용은 개역개정입니다.
